# CAS 小组人工录入包

本目录只整理原始资料，不写入网站数据库或代码。每个小组目录包含一份 `资料.md`、统一命名的图标（如有）和最近一次线下活动图片。

## 目录与网站字段

- `名字`：小组正式名称。
- `图标`：对应 `icon.jpg`；没有独立图标时明确标为“未提供”，不要拿活动照片冒充图标。
- `简介`：优先采用原始资料中的中文正文，仅做轻微标点整理。
- `最近一次线下活动`：一段简述，加 `activity-*.jpg` 图片列表。
- `成员列表（和联系方式）`：保留原文姓名和联系值；联系方式类型不明确时标为“未注明”，不擅自判断为电话或微信。

`人工录入参考.json` 提供相同信息的结构化版本，便于人工复制或后续另写导入脚本。它不是当前数据库可直接执行的迁移文件。

## 网站公开素材目录

图标和活动图片另复制到网站的 `public/CAS/` 目录，和 `public/Photos/` 同级。`人工录入参考.json` 中的图片字段使用可直接填入网站的 `/CAS/...` URL。包含成员联系方式的 Markdown 与 JSON 只保留在本人工录入包中，不复制到 `public/`。

## 与当前网站实现有关的提醒

当前网站已支持在项目成员关系中保存负责人/成员身份以及可选的联系方式类型和值。COMPESISTANT 的原始资料没有明确标注负责人和联系方式类型；本次根据资料提供者授权，将唯一留有对外联系方式的 David 设为负责人，并把 11 位中国大陆手机号按电话录入。

此外，新建项目还需要分类、年份和 CAS 三项标记。COMPESISTANT 按项目内容归入“科技创新”，年份采用资料提供者确认的 2026，CAS 标记为 Creativity 与 Service，热度沿用数据库默认值 0。

Ride Royce 的材料可确认活动发生在 2026 年，且项目以 CAS Action 为主；这两项属于网站的扩展字段，不在本整理包要求的五项资料内，因此仅保留在小组说明中供人工判断。

COMPESISTANT 的原始资料还包含已完成事项和学期计划，因此在该小组的 Markdown、TXT 和 JSON 中保留了扩展章节；这些内容可以后续整理为项目动态，但原文没有提供发布日期，不应虚构时间。
