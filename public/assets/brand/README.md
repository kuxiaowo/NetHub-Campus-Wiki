# NetHub Linked N

Vector master for the C / Linked N direction selected by the project owner on 2026-10-28. The geometry is redrawn as clean SVG paths from the approved AI-assisted visual concept; the SVG is the source of truth, not the concept sheet PNG.

- `nethub-mark.svg`: brand blue (#3157d5), transparent background.
- `nethub-mark-light.svg`: pale blue (#a9c7ff) for dark surfaces.
- `favicon.svg`, `favicon-16.png`, `favicon-32.png`: browser icons.
- `nethub-mark-512.png`: transparent raster export.

Use one mark across Wiki and Accounts, paired with the live-text NetHub wordmark and the product name. Keep aspect ratio and internal clear space; do not stretch or add effects. Decorative images beside a text wordmark should use empty alt text.
