# 照片压缩

在项目根目录运行（需要 requirements.txt 中已有的 Pillow）：

```powershell
python scripts/compress_photos.py
```

默认源目录为项目内 `public/Photos/2025级九寨沟CAS WEEK`，输出为项目同级的 `2025级九寨沟CAS WEEK-compressed`，目标为十进制 4 GB（允许 ±5%，包括缩略图）。输出目录必须为空，原照片不会改动。

自定义示例：

```powershell
python scripts/compress_photos.py --source "D:\照片" --output "D:\照片-compressed" --target-gb 4
```

保留像素尺寸、JPEG 色度采样、EXIF（包括方向）和 ICC 信息，不转换格式；缩略图及其他文件原样复制。先按文件大小分层抽样估算，再进行全量实测，从 95 向下检查到 75，选择符合上限的最高统一质量。每轮均从原图编码，编码文件更大时保留原文件。为避免 JPEG 体积不严格单调导致误判，最多可能进行约 22 轮全量编码；大量高分辨率照片会比较耗时。

运行期间输出目录只是中间结果，不要将其用于替换原相册。需要足够磁盘空间容纳高质量中间结果，保守建议预留相当于源目录大小的可用空间。完成后请自行检查人物、暗部和细节丰富照片的实际观感；质量参数不是画质保留百分比。

退出码：`0` 表示完成且达到目标；`2` 表示完成但目标不可达（质量 75 仍太大，或质量 95 已低于下限）；`1` 表示错误；`130` 表示主动中断。错误或中断后输出可能不完整，请检查并另选空目录重试。脚本不自动删除已有输出，也不启动任何服务。
